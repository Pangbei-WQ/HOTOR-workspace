## 三、关键字段

- **销售等级**（D/E/F…）：来自匹配表 G 列，即京东「全国7日三级销量 band」
- **目标周转**：由销售等级经参数表 VLOOKUP 得出（天数，约 20–35 天）
- **有货率系数**：由销售等级经参数表 VLOOKUP 得出（约 1–1.5）
- **波动系数**：见下，需求不确定性的量化指标

## 四、波动系数（需求不确定性的量化）

销售趋势表 I 列公式（原文）：

```
波动系数 = ROUND( STDEV.S(近31天日销) / AVERAGE(近31天日销), 2 )
```

即**变异系数 CV = 标准差 / 均值**，基于最近 31 天日销序列（K 至 AN 列，共 31 列）。

## 五、方法 A：移动加权平均法

### 加权日销
```
7天权重  = IF(波动系数≤0.2, 0.3, 波动系数≤0.4, 0.4, 波动系数≤0.6, 0.6, 否则 0.8)
28天权重 = IF(波动系数≤0.2, 0.7, 波动系数≤0.4, 0.6, 波动系数≤0.6, 0.4, 否则 0.2)
加权日销 = 7天权重 × (近7日出库/7) + 28天权重 × (近28日出库/28)
```
7/28 天权重随波动系数分 4 档**自适应**：波动越大，越重仓近期（7 天）。

### 补货量（计划量）
```
补货量 = IF(加权日销 × 目标周转 − 可订购库存 > 0, ROUND(加权日销 × 目标周转 − 可订购库存, 0), 0)
       = MAX(0, 加权日销 × 目标周转 − 可订购库存)
```
> 安全缓冲隐含在较高的目标周转天数里；使用「可订购库存」（含在途）。

### 参数表（第 2–6 行）
目标周转（随销售等级）：35 / 35 / 30 / 25 天；7 天权重 0.3 / 0.4 / 0.6 / 0.8；28 天权重 0.7 / 0.6 / 0.4 / 0.2。

## 六、方法 B：有货率 + 安全库存法

### 加权日销（权重固定）
```
加权日销 = 0.8 × (近7日出库/7) + 0.2 × (近28日出库/28)
```
始终重仓近期（7 天权重 0.8），权重不随波动系数变化。

### 安全库存（显式叠加）
```
安全库存天数 = 目标周转 × 波动系数 × 0.3 × 有货率系数
补货量 = MAX(0, 加权日销 × (目标周转 + 安全库存天数) − 可用库存)
```
> 基础周转（目标周转）+ 显式安全库存分开；使用「可用库存」（需扣在途）。

### 参数表（第 2–6 行）
目标周转：25 / 25 / 20 / 20 天；有货率系数：约 1.5 / 1.3 / 1.1 / 1；7/28 天权重固定 0.8 / 0.2。

## 七、样本数据实例（SKU 100215382127 洛米企鹅安抚巾，销售等级 D，波动系数 0.26）

**方法 A（北京仓）**：
- 近 7 日出库 195，近 28 日出库 876
- 波动系数 0.26 ≤ 0.4 → 7 天权重 0.4，28 天权重 0.6
- 加权日销 = 0.4×195/7 + 0.6×876/28 = 11.14 + 18.77 = 29.91
- 目标周转 30，可订购库存 585 → 补货量 = 29.91×30 − 585 ≈ 312

**方法 B（北京仓）**：
- 加权日销 = 0.8×195/7 + 0.2×876/28 = 22.29 + 6.26 = 28.54
- 目标周转 20，有货率系数 1 → 安全库存天数 = 20×0.26×0.3×1 = 1.56
- 总覆盖天数 = 21.56，可用库存 455 → 补货量 = 28.54×21.56 − 455 ≈ 160

## 八、两方法的关键差异

| 维度 | 方法 A（移动加权平均） | 方法 B（有货率+安全库存） |
|------|---------------------|------------------------|
| 7/28 天权重 | 随波动系数分 4 档自适应 | 固定 0.8 / 0.2 |
| 安全库存 | 隐含在较高目标周转（30 天）里 | 显式：目标周转×波动系数×0.3×有货率系数 |
| 库存口径 | 可订购库存（含在途） | 可用库存（需扣在途） |
| 基础周转 | 较高 | 较低（20 天）+ 显式安全天数 |
