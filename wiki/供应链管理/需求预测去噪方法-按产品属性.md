# 需求预测去噪方法（按产品属性）

> **状态**：unreviewed
> **最后更新**：2026-10-29
> **来源**：综合 [[wiki/供应链管理/SOP方法与刘宝红计划方法对比]]（预测模型与削峰填谷）、[[wiki/供应链管理/学习小组/庞贝-需求预测与产品属性]]（长尾/短尾分类）、[[计划岗答疑纪要-2026-10-28]]（领星预测模型"如何去噪"待办）
> 本页回答：领星/预测模型需要界定的「如何去噪」问题，按产品属性给出几种方法。

## 核心要点

- **去噪的本质**：把需求历史里「一次性、不可重复」的成分（促销峰、断货谷、异常大单、上架爬坡）从「可重复的基准需求」中剥离，让统计模型只学到正常需求水平——即刘宝红的「削峰填谷」数据清洗
- **通用底座**：加一列「数据性质」标记（正常/促销/断货/清仓/大单）+ 削峰 + 填谷 + 周汇总，去噪可追溯
- **分型方法**：长尾看异常大单与 0 值、季节品看同比与季节指数、大促品看促销峰拆分、新品靠类比 + 滚动纠偏、断货品靠填谷

## 详细内容

### 0. 通用底座（所有类型共用）

（综合 [[wiki/供应链管理/SOP方法与刘宝红计划方法对比]] §四·数据清洗 与 §六·最小改动路径）

1. **加"数据性质"标记列**（最小改动）：在销量表给每一周打标 `正常 / 促销 / 断货 / 清仓 / 大单`，让模型知道哪些点该降权或剔除——去噪必须可追溯。
2. **削峰**：促销/大促周 → 用「促销前 4–8 周正常周的中位数」替换掉尖峰。
3. **填谷**：断货/下架周 → 用「断货前正常周的中位数」补齐虚低。
4. **周汇总 + 基准/增量分离**：基准（模型算）+ 增量（判断加），噪声只影响"增量"那一段。

> 💡 每做一次替换/剔除都留记录，复盘时才能分清"是模型不准"还是"清洗错了"。

### 1. 长尾产品（低频零散出单）

**噪声源**：出单稀疏、大量 0 值周、偶发的异常大单（批发/团购单）。

- **剔异常大单**：单笔远超常规量级的批发单，当结构性噪声剔除（不代表日常需求）
- **聚合再预测**：单周 0 值太多 → 聚到更长颗粒度（周→月）或同品类聚合，减少随机噪声
- **用泊松而非正态**（来源事实）：长尾出单不满足正态假设，用泊松模拟更准（见 [[wiki/供应链管理/SOP方法与刘宝红计划方法对比]] §四）
- **区分「断货 0」与「无需求 0」**：0 值周要查是没卖出去还是没货卖，别把断货误判成无需求

### 2. 季节品（强季节性）

**噪声源**：季节本身是"信号"，真正的噪声是季节内波动 + 叠加的大促峰。

- **用同比、不用环比**：对比去年同期同季节，天然去掉了季节性
- **季节指数法**（霍尔特-温特 γ）：先算季节指数，再用"去季节化"后的序列做基准预测
- **区分「自然季节」与「人造大促峰」**（综合判断）：大促是人工制造的峰，应清洗，不建进季节模型（库内已有此判断）
- **季节性判断需 ≥2 年历史**：避免把一次偶然波动当成季节规律

### 3. 经过大促的产品（有促销历史）

**噪声源**：促销尖峰不可重复，直接进基准会系统性抬高预测。

- **削峰**：促销周销量 → 替换为促销前 4–8 周正常周中位数
- **促销贡献拆分**：`促销周销量 = 基准销量 + 促销增量`，只把"基准销量"喂给模型，"促销增量"用判断单独估
- **标记「促销」降权/剔除**：让模型忽略促销周
- **周期性大促单列**：若每年固定节点（黑五/Prime Day），用事件因子单独建模，不混进日销基准

### 4. 新品 / 爬坡期

**噪声源**：没有可清洗的历史；上架初期销量是"爬坡"，不是稳态需求。

- **类比法**：用同类产品（同品类/价格带/流量结构）历史做基准（见 [[wiki/供应链管理/SOP方法与刘宝红计划方法对比]] §四·亚马逊场景映射 5）
- **滚动预测快速纠偏**：数据点少，用滚动预测小步快走
- **霍尔特设下限**：爬坡期用趋势模型但设下限，避免过度外推
- **预热数据点**：前几周作为"预热"不作为去噪对象，先积累基线

### 5. 断货过的产品

**噪声源**：断货造成销量"虚低"，直接算均值会低估真实需求。

- **填谷**：断货期 → 用断货前正常周销量水平补齐
- **标记「断货」并排除该区间**：让模型跳过断货周，不参与均值/趋势计算

> 💡 **LLM 推断**：本节「剔异常大单、削峰填谷、泊松用于长尾、同比去季节、季节指数」来自刘宝红方法与庞贝长尾/短尾分类（来源事实）；「4–8 周中位数、促销贡献拆分、聚合到月」等具体参数为综合判断，未经验证，落地时需用真实数据标定。
