# 霍尔特法（Holt，双参数指数平滑 / 趋势模型）

> **状态**：unreviewed
> **最后更新**：2026-11-16
> **来源**：[[raw/知识文件归档/供应链管理-刘宝红/6、《需求预测和库存计划  一个实践者的角度》2020年]]、[[wiki/供应链管理/SOP方法与刘宝红计划方法对比]]

## 核心要点

- 霍尔特法 = 在简单指数平滑的**水平**基础上，再增加一个**趋势**部分，两维分别平滑
- 两个平滑系数：α（水平）、β（趋势），都介于 0~1
- 能**外推多期**：未来第 n 期预测 = 水平 + n × 趋势
- ⚠️ **有过度外推倾向**——趋势一路往下时会外推成负数，需设下限
- 适用：**有趋势**（爬坡 / 下滑），如新品爬坡、加大广告、BSR 持续上升

## 详细内容

### 计算公式

> 📌 来源事实（刘宝红《需求预测和库存计划》）

预测由"水平部分"和"趋势部分"两部分构成，各用一次简单指数平滑更新，相加得下期预测：

```
本期水平 L(t) = α·X(t) + (1−α)·(L(t−1) + T(t−1))
本期趋势 T(t) = β·(L(t) − L(t−1)) + (1−β)·T(t−1)
下期预测  F(t+1) = L(t) + T(t)
未来第 n 期 F(t+n) = L(t) + n·T(t)
```

- `L(t)`：第 t 期水平（"平均值"）；`T(t)`：第 t 期趋势（"每期增量"）；`X(t)`：第 t 期实际
- `α`：水平平滑系数；`β`：趋势平滑系数

**初始化**（来源事实）：初始水平 `L₁` 取第一个实际值；初始趋势 `T₁` 取第二个实际值减第一个实际值（也可用前几期线性回归的截距/斜率，或干脆设 T₁=0）。初始值影响随迭代衰减。

### 实际算例（α = 0.5，β = 0.4）

> 💡 LLM 算例（演示数据，数值四舍五入到 2 位小数）

某爬坡款 SKU 连续 5 周销量 `100, 110, 125, 135, 150`（明显上升）。初始化：L₁ = 100，T₁ = 110 − 100 = 10。

```
第2周：L2 = 0.5×110 + 0.5×(100+10) = 55 + 55      = 110
      T2 = 0.4×(110−100) + 0.6×10    = 4 + 6       = 10
      F3 = 110 + 10 = 120

第3周：L3 = 0.5×125 + 0.5×(110+10) = 62.5 + 60    = 122.5
      T3 = 0.4×(122.5−110) + 0.6×10 = 5 + 6        = 11
      F4 = 122.5 + 11 = 133.5

第4周：L4 = 0.5×135 + 0.5×(122.5+11) = 67.5 + 66.75 = 134.25
      T4 = 0.4×(134.25−122.5) + 0.6×11 = 4.7 + 6.6   = 11.3
      F5 = 134.25 + 11.3 = 145.55

第5周：L5 = 0.5×150 + 0.5×(134.25+11.3) = 75 + 72.775 = 147.78
      T5 = 0.4×(147.78−134.25) + 0.6×11.3 = 5.41 + 6.78 = 12.19
      F6 = 147.78 + 12.19 = 159.97
```

| 周 t | 实际 X | 水平 L | 趋势 T | 下期预测 F(t+1) |
|------|--------|--------|--------|-----------------|
| 1    | 100    | 100    | 10     | —               |
| 2    | 110    | 110    | 10     | 120             |
| 3    | 125    | 122.5  | 11     | 133.5           |
| 4    | 135    | 134.25 | 11.3   | 145.55          |
| 5    | 150    | 147.78 | 12.19  | **159.97**      |

MSE（F3~F5 vs 实际 125/135/150）：

```
MSE = [(120−125)² + (133.5−135)² + (145.55−150)²] / 3
    = (25 + 2.25 + 19.80) / 3 ≈ 15.7
```

### 多期外推算例

> 💡 LLM 算例：以第 5 周的水平与趋势，外推未来 3 周

```
第6周 F(5+1) = 147.78 + 1×12.19 = 159.97
第7周 F(5+2) = 147.78 + 2×12.19 = 172.16
第8周 F(5+3) = 147.78 + 3×12.19 = 184.35
```

> ⚠️ 来源事实：霍尔特法能外推多期，但有**过度外推**倾向——刘宝红原书案例里，趋势为负时"第 22 周预测 22、第 23 周预测 4、第 24 周就成负数"，明显不合理。**爬坡款/下滑款使用时务必设下限**（如预测不低于 0，或下限 = 一定天数的最低销量）。

## 适用与要点

| 项目 | 说明 |
|------|------|
| **适用** | 有趋势（爬坡 / 下滑）的产品，如新品爬坡、加大广告、BSR 持续上升 |
| **对比** | 简单指数平滑法在趋势场景会"步步紧逼"、永远滞后一步；霍尔特加了趋势项，能"预判走向" |
| **亚马逊落地** | 排名上升期用霍尔特；⚠️ 设下限防过度外推 |
| **参数择优** | α、β 用 Excel Solver 以 MSE 最小为目标联合优化 |
