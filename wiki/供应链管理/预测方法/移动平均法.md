# 移动平均法（Moving Average, MA）

> **状态**：unreviewed
> **最后更新**：2026-11-16
> **来源**：[[raw/知识文件归档/供应链管理-刘宝红/6、《需求预测和库存计划  一个实践者的角度》2020年]]、[[wiki/供应链管理/SOP方法与刘宝红计划方法对比]]

## 核心要点

- 移动平均 = 平均最近 N 期历史，用平均值消除需求波动中的**随机因素**
- 期数 N 越大越平稳、越迟钝；N 越小越灵敏、越被动。**择优靠回测比 MSE**
- 权重一样叫简单移动平均；权重不同（越新越大）叫加权移动平均
- 适用：**平稳、无趋势、无季节性**；有趋势→二次移动平均或霍尔特法，有季节+趋势→霍尔特-温特

## 详细内容

### 计算公式

> 📌 来源事实（刘宝红《需求预测和库存计划》）

**简单移动平均**（每期历史权重一样）：

```
F(t+1) = (X(t) + X(t−1) + … + X(t−N+1)) / N
```

**加权移动平均**（权重越新越大，总和 = 1）：

```
F(t+1) = w1·X(t) + w2·X(t−1) + … + wN·X(t−N+1)，  Σw = 1
```

### 实际算例（4 周移动平均）

> 💡 LLM 算例（演示数据）

某 SKU 连续 8 周销量 `100, 104, 98, 102, 106, 100, 108, 104`，做 **4 周移动平均**，从第 5 周开始出预测：

```
F5 = (100+104+98+102) / 4 = 404 / 4 = 101
F6 = (104+98+102+106) / 4 = 410 / 4 = 102.5
F7 = (98+102+106+100) / 4 = 406 / 4 = 101.5
F8 = (102+106+100+108) / 4 = 416 / 4 = 104
F9 = (106+100+108+104) / 4 = 418 / 4 = 104.5
```

| 周 | 实际销量 X | 4 周 MA 预测 F | 误差（实际−预测） |
|----|-----------|---------------|------------------|
| 1  | 100       | —             | —                |
| 2  | 104       | —             | —                |
| 3  | 98        | —             | —                |
| 4  | 102       | —             | —                |
| 5  | 106       | 101           | +5               |
| 6  | 100       | 102.5         | −2.5             |
| 7  | 108       | 101.5         | +6.5             |
| 8  | 104       | 104           | 0                |
| 9  | —         | **104.5**     | —                |

**第 9 周预测 = 104.5**。均方误差：

```
MSE(4周) = (5² + 2.5² + 6.5² + 0²) / 4 = (25 + 6.25 + 42.25 + 0) / 4 = 73.5 / 4 ≈ 18.4
```

### 加权移动平均算例

> 💡 LLM 算例（演示数据）

近 3 周销量 X(t)=104、X(t−1)=108、X(t−2)=100，权重取 0.5 / 0.3 / 0.2（越新越重）：

```
F(t+1) = 0.5×104 + 0.3×108 + 0.2×100 = 52 + 32.4 + 20 = 104.4
```

### 期数择优（MSE 回测）

> 📌 来源事实（刘宝红原书表 1-1 案例）

均方误差公式：

```
MSE = (1/n) × Σ(实际值 − 预测值)²
```

期数常用 **2 / 4 / 6 / 8 / 13 周**（2 周≈半月、4 周≈1 个月、8 周≈2 个月、13 周≈1 季度），有利于跨职能沟通。

原书用一个 13 周历史复盘 14~26 周的案例，比较不同期数的平均均方误差：

| 期数 | 平均均方误差 |
|------|-------------|
| 2 周 | 150.7       |
| 6 周 | **128.9**   |

> 6 周比 2 周低 17%，选 6 周。说明**期数不是越灵敏越好**：2 周太灵敏、跟着随机波动跑；期数过长（8/13 周）又与实际变动渐行渐远。准确度随期数先升后降，需回测找拐点。

## 适用与要点

| 项目 | 说明 |
|------|------|
| **适用** | 需求相对平稳，无趋势、无季节性 |
| **预测范围** | 预测下期；更远的期默认跟下期一样（水平外推） |
| **趋势场景** | 二次移动平均（对一次 MA 再 MA），或改用霍尔特法 |
| **季节场景** | 改用霍尔特-温特法 |
