# 霍尔特-温特法（Holt-Winters，趋势 + 季节模型）

> **状态**：unreviewed
> **最后更新**：2026-11-16
> **来源**：[[raw/知识文件归档/供应链管理-刘宝红/6、《需求预测和库存计划  一个实践者的角度》2020年]]、[[wiki/供应链管理/SOP方法与刘宝红计划方法对比]]

## 核心要点

- 时间序列可分解为三成分：**水平（平均值）+ 趋势（升/降）+ 季节（周期性重复）**，剩余是随机变动
- 霍尔特-温特 = 在霍尔特（水平+趋势）基础上**再加"季节"成分**，三者各自平滑
- 三个平滑系数：α（水平）、β（趋势）、γ（季节）——参数多、优化难，但拟合度最高
- 有两种做法：**季节指数分解法**（简单、静态、Excel 友好）和**三参数递归平滑**（自适应、动态）
- 适用：**趋势 + 季节性并存**（自然季节）；⚠️ 大促是"人工制造的峰"，应**当异常清洗**而非建进季节模型

## 详细内容

### 方法一：季节指数分解法（刘宝红详例，Excel 友好）

> 📌 来源事实：刘宝红原书用"求季节指数 → 去季节化 → 线性回归求趋势 → 季节反算"四步处理"季节性+趋势"并存的时间序列。

**第 1 步：求季节指数** = 该期多年平均值 ÷ 总平均值。

**第 2 步：去季节化** = 每期实际值 ÷ 对应季节指数，得到"假定没有季节性"的序列。

**第 3 步：线性回归** = 对去季节化序列用 `需求 = a + b × 期数` 求趋势（斜率 b 即每期增量）。

**第 4 步：季节反算** = 线性预测 × 季节指数，得到最终预测。

#### 实际算例（3 年 × 4 季度）

> 💡 LLM 算例（演示数据）

某季节款连续 3 年 12 个季度销量（每 4 期一个季节周期，且逐年递增）：

| 年份 | Q1 | Q2 | Q3 | Q4 |
|------|-----|-----|-----|-----|
| 第 1 年 | 100 | 160 | 140 | 80 |
| 第 2 年 | 110 | 176 | 154 | 88 |
| 第 3 年 | 120 | 192 | 168 | 96 |

**第 1 步：季节指数**

```
各季多年平均：Q1 = (100+110+120)/3 = 110；Q2 = (160+176+192)/3 = 176
              Q3 = (140+154+168)/3 = 154；Q4 = (80+88+96)/3   = 88
总平均 = (100+160+140+80+110+176+154+88+120+192+168+96)/12 = 1584/12 = 132
季节指数 = 各季平均 / 总平均
```

| 季度 | 多年平均 | 季节指数 |
|------|----------|----------|
| Q1 | 110 | 110/132 = 5/6 ≈ 0.83 |
| Q2 | 176 | 176/132 = 4/3 ≈ 1.33 |
| Q3 | 154 | 154/132 = 7/6 ≈ 1.17 |
| Q4 | 88  | 88/132  = 2/3 ≈ 0.67 |

（四个指数相加 = 4，校验通过。Q2 是旺季、Q4 是淡季。）

**第 2 步：去季节化**（实际 ÷ 季节指数）：

```
第1年：100/(5/6)=120，160/(4/3)=120，140/(7/6)=120，80/(2/3)=120
第2年：110/(5/6)=132，176/(4/3)=132，154/(7/6)=132，88/(2/3)=132
第3年：120/(5/6)=144，192/(4/3)=144，168/(7/6)=144，96/(2/3)=144
```

去季节化后：第 1 年每季 120、第 2 年 132、第 3 年 144，即**每季 +3**。

**第 3 步：线性回归**（期数 t = 1~12，去季节化值 y）：

```
斜率 b = 3（每季 +3）；截距 a = 117（t=1 时 y=120 → a + 3×1 = 120 → a = 117）
趋势方程：ŷ(t) = 117 + 3t
```

**第 4 步：季节反算**（第 4 年，t = 13~16）：

```
F(13) = (117 + 3×13) × 5/6 = 156 × 5/6 = 130
F(14) = (117 + 3×14) × 4/3 = 159 × 4/3 = 212
F(15) = (117 + 3×15) × 7/6 = 162 × 7/6 = 189
F(16) = (117 + 3×16) × 2/3 = 165 × 2/3 = 110
```

| 季度（第 4 年） | 线性预测 ŷ | 季节指数 | 最终预测 F |
|-----------------|-----------|----------|-----------|
| Q1 | 156 | 5/6 | 130 |
| Q2 | 159 | 4/3 | 212 |
| Q3 | 162 | 7/6 | 189 |
| Q4 | 165 | 2/3 | 110 |

第 4 年全年预测 = 130 + 212 + 189 + 110 = 641，比第 3 年（576）增长约 11%，与逐年增速吻合。

> 📌 来源事实（刘宝红原书更简的例）：上年四季度 2000/3500/3000/1500，均值 2500 → 季节指数 0.8/1.4/1.2/0.6；若业务年增 30%，下年总预测 13000、季均 3250 → 各季预测 2600/4550/3900/1950。结构与上面算例完全同源。

### 方法二：霍尔特-温特三参数递归平滑（自适应版）

> 📌 来源事实：霍尔特-温特在霍尔特（α、β）基础上增加季节平滑系数 γ，三者分别平滑；相比方法一，能通过调参持续拟合，是"动态"版。乘法式公式如下：

```
水平  L(t) = α·(X(t)/S(t−m)) + (1−α)·(L(t−1) + T(t−1))
趋势  T(t) = β·(L(t) − L(t−1)) + (1−β)·T(t−1)
季节  S(t) = γ·(X(t)/L(t)) + (1−γ)·S(t−m)
预测  F(t+n) = (L(t) + n·T(t)) · S(t+n−m)
```

- `m`：季节周期长度（按季 m=4、按月 m=12）；`S(t)`：第 t 期的季节指数
- **初始化**：季节指数的初值可用方法一求得（各季平均/总平均），水平/趋势初值同霍尔特法；之后每期递归更新，季节指数会随新数据自适应漂移
- 三个参数的优化（尤其 γ）比单参数难，大部分人难驾驭——用不好反而更差，这是它的主要代价

## 适用与要点

| 项目 | 说明 |
|------|------|
| **适用** | 自然季节性 + 趋势并存：圣诞、黑五、Prime Day、节日款、商用车/热饮等 |
| **亚马逊落地** | 强季节款用霍尔特-温特；⚠️ **大促是"人工制造的峰"不是自然季节**，应削峰填谷当异常清洗，而不是建进季节模型 |
| **周期 vs 季节** | 周期无固定规律（可预见性低），季节有固定规律——别把商业周期误当季节建模 |
| **数据要求** | 至少覆盖 2~3 个完整季节周期才可靠 |
