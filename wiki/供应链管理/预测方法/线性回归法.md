# 线性回归法（Linear Regression，基于相关性）

> **状态**：unreviewed
> **最后更新**：2026-11-16
> **来源**：[[raw/知识文件归档/供应链管理-刘宝红/6、《需求预测和库存计划  一个实践者的角度》2020年]]、[[wiki/供应链管理/SOP方法与刘宝红计划方法对比]]

## 核心要点

- 前面几种方法基于**需求的延续性**（时间序列），线性回归基于**相关性**（两个变量间的线性关系）
- 回归方程 `y = a + bx`：`b` 是倍数（斜率），`a` 是常数（截距）；用**最小二乘法**（均方误差总和最小）求直线
- 用 **R²** 判断线性关系强弱：R² 越接近 1 越强；R² 接近 0 = 没有线性关系
- ⚠️ 相关性 ≠ 因果性；R² 高不代表能乱用
- 适用：**数据有限（新品）**、类似产品类比、流量/广告投入等驱动变量明确的场景

## 详细内容

### 计算公式

> 📌 来源事实（刘宝红《需求预测和库存计划》）

回归方程：

```
y = a + b·x
```

- `x`：自变量（如流量、广告投入、同类老品销量）；`y`：因变量（要预测的销量）

最小二乘法求参数（让所有样本的均方误差总和最小）：

```
b = Σ[(x − x̄)(y − ȳ)] / Σ[(x − x̄)²] = (n·Σxy − Σx·Σy) / (n·Σx² − (Σx)²)
a = ȳ − b·x̄
```

拟合优度（线性关系强弱）：

```
R² = 1 − SSE/SST = 1 − Σ(y − ŷ)² / Σ(y − ȳ)²
```

- `ŷ`：回归预测值；`ȳ`：y 的平均值；`x̄`：x 的平均值；R² 介于 0~1

### 实际算例（流量 vs 销量）

> 💡 LLM 算例（演示数据）

某链接 5 周数据：流量 x（千次）`1, 2, 3, 4, 5`，销量 y（件）`22, 38, 47, 62, 76`。

```
n = 5；Σx = 15，x̄ = 3；Σy = 245，ȳ = 49
Σxy = 1×22 + 2×38 + 3×47 + 4×62 + 5×76 = 22 + 76 + 141 + 248 + 380 = 867
Σx² = 1 + 4 + 9 + 16 + 25 = 55

b = (5×867 − 15×245) / (5×55 − 15²) = (4335 − 3675) / (275 − 225) = 660 / 50 = 13.2
a = 49 − 13.2×3 = 49 − 39.6 = 9.4

回归方程：ŷ = 9.4 + 13.2x
```

| x（千次） | 实际 y | 预测 ŷ = 9.4+13.2x | 残差 y−ŷ |
|-----------|--------|--------------------|----------|
| 1 | 22 | 22.6 | −0.6 |
| 2 | 38 | 35.8 | +2.2 |
| 3 | 47 | 49.0 | −2.0 |
| 4 | 62 | 62.2 | −0.2 |
| 5 | 76 | 75.4 | +0.6 |

```
SSE = 0.36 + 4.84 + 4 + 0.04 + 0.36 = 9.6
SST = (22−49)² + (38−49)² + (47−49)² + (62−49)² + (76−49)²
    = 729 + 121 + 4 + 169 + 729 = 1752
R² = 1 − 9.6/1752 = 1 − 0.0055 ≈ 0.99
```

**解读**：b = 13.2 → 流量每多 1 千次，销量约多 13.2 件；R² ≈ 0.99 → 线性关系极强，可用来预测。

**预测**：下周预计流量 5.5 千次 → `ŷ = 9.4 + 13.2×5.5 = 9.4 + 72.6 = 82` 件。

### 反例：R² 极小时"趋势"是假的

> 📌 来源事实（刘宝红原书图 1-11 案例）：某个看似有趋势的需求折线图，Excel 显示回归方程 `y = 0.4065x + 13.005`，但 **R² = 0.0137**（调整后 R² 甚至为负），说明需求和时间之间的回归关系极弱——**"看着有条趋势线，不等于真有趋势"**。别被 Excel 随手画的趋势线骗了，要看 R²。

## 适用与要点

| 项目 | 说明 |
|------|------|
| **适用** | 数据有限的新品（无历史）、类似产品类比（同品类/价格带/流量结构 ASIN）、流量/广告投入等驱动变量明确 |
| **新品落地** | 用同类 ASIN 历史做相关性回归 + 德尔菲专家判断，预售期数据点少要**滚动预测**尽快纠偏 |
| **警惕** | ① 相关性≠因果性（预售卖得好≠正式卖得好只是相关）；② 残差需大体正态、方差齐，否则置信区间/显著性检验不可信；③ R² 低时别硬套 |
