# 简单指数平滑法（Simple Exponential Smoothing, ES）

> **状态**：unreviewed
> **最后更新**：2026-11-16
> **来源**：[[raw/知识文件归档/供应链管理-刘宝红/6、《需求预测和库存计划  一个实践者的角度》2020年]]、[[wiki/供应链管理/SOP方法与刘宝红计划方法对比]]

## 核心要点

- 简单指数平滑 = 一种**加权移动平均**，权重按**几何级数衰减**，越新的数据权重越大
- 只需保留两个数（上次实际值 + 上次预测值）就能算出下次预测，工作量极小
- α 越大越灵敏、越容易过度反应；α 越小越平稳、越可能响应慢。**择优靠回测比 MSE**
- 适用：**平稳**、无明显趋势/季节性的场景，是最常用的预测方法之一

## 详细内容

### 计算公式

> 📌 来源事实（刘宝红《需求预测和库存计划》式 1-1 / 1-2）

基本式：

```
F(t+1) = α·X(t) + (1−α)·F(t)
```

误差修正式（等价写法）：

```
F(t+1) = F(t) + α·(X(t) − F(t))
```

- `F(t+1)`：下一期预测；`X(t)`：本期实际；`F(t)`：本期预测；`α`：平滑系数（0~1）

**"指数"从哪来**——把基本式逐期展开，历史各期权重按 `α(1−α)` 的幂衰减：

```
F(t+1) = α·X(t) + α(1−α)·X(t−1) + α(1−α)²·X(t−2) + α(1−α)³·X(t−3) + …
```

**α 的两个极端**：

| α 取值 | 行为 | 效果 |
|--------|------|------|
| α = 0  | 完全沿用上期预测（"我行我素"） | 最平稳，但永远不响应变化 |
| α = 1  | 完全用上期实际值（= 幼稚预测） | 最灵敏，但被动反应、永远慢一拍 |
| 0 < α < 1 | 实际与预测加权折中 | 平稳与响应间取平衡 |

### 实际算例（α = 0.5）

> 💡 LLM 算例（演示数据）

某 SKU 连续 5 周销量 `100, 120, 90, 130, 110`，令 F₁ = 100，α = 0.5：

```
F2 = 0.5×100 + 0.5×100 = 100
F3 = 0.5×120 + 0.5×100 = 60 + 50  = 110
F4 = 0.5×90  + 0.5×110 = 45 + 55  = 100
F5 = 0.5×130 + 0.5×100 = 65 + 50  = 115
F6 = 0.5×110 + 0.5×115 = 55 + 57.5 = 112.5
```

| 周 | 实际 X | 预测 F | 误差（实际−预测） |
|----|--------|--------|------------------|
| 1  | 100    | 100    | —                |
| 2  | 120    | 100    | +20              |
| 3  | 90     | 110    | −20              |
| 4  | 130    | 100    | +30              |
| 5  | 110    | 115    | −5               |
| 6  | —      | **112.5** | —             |

**第 6 周预测 = 112.5**。MSE：

```
MSE(α=0.5) = (20² + 20² + 30² + 5²) / 4 = (400 + 400 + 900 + 25) / 4 = 1725 / 4 = 431.25
```

### α 择优（同一组数据回测比 MSE）

> 💡 LLM 算例：同一组数据 `100, 120, 90, 130, 110`，套三个 α 复盘 5 周

| α  | 预测序列 F2~F5          | MSE     |
|----|------------------------|---------|
| 0.2 | 100, 104, 101.2, 106.96 | **358.7** |
| 0.5 | 100, 110, 100, 115     | 431.25  |
| 0.8 | 100, 116, 95.2, 123.04 | 614.27  |

> 结论：数据偏平稳时**小 α（0.2）最优**。α 越大越灵敏，反而放大了随机"杂音"。

> 📌 来源事实：经验上取 α 值一般每个相差 0.05 试算，复盘过去 13 周，选 MSE 最小者；进阶用 Excel Solver 设"均方误差最小"自动求最优 α。

### α 经验值（来源事实）

| 需求历史形态 | α 经验值 |
|-------------|----------|
| 比较稳定 | 0.05 ~ 0.2 |
| 有波动，长期趋势无大变化 | 0.1 ~ 0.4 |
| 波动很大，明显且迅速的升/降趋势 | 0.6 ~ 0.8 |
| 明显上升或下降序列 | 0.6 ~ 1 |

### 初始化与"预热"（来源事实）

- **初始预测 F₁**：可取上期实际值、移动平均值、或随便填 0——初始值影响随迭代**几何级衰减**，几期后基本消失
- **预热**：一般用最初 **9 个数据点**做初始化，之后约 **12 期**做测试组回测评 α
- ⚠️ 预热数据与测试数据**必须分离**，避免"既当裁判又当球员"

## 适用与要点

| 项目 | 说明 |
|------|------|
| **适用** | 平稳、无趋势无季节；B2C 促销多、需求关联性高的场景（能快速捡起新信号） |
| **亚马逊落地** | 成熟稳定款 α 取 0.1~0.3，替代 SOP 的【控制日销】；数据源用后台销量按周汇总、口径统一 |
| **局限** | 适合短期（下一期）预测；有趋势/季节时一直"追赶"，需换霍尔特/霍尔特-温特 |
