# 幼稚预测法（Naive Forecast）

> **状态**：unreviewed
> **最后更新**：2026-11-16
> **来源**：[[raw/知识文件归档/供应链管理-刘宝红/6、《需求预测和库存计划  一个实践者的角度》2020年]]、[[wiki/供应链管理/SOP方法与刘宝红计划方法对比]]

## 核心要点

- 幼稚预测 = **用上期实际需求当作下期预测**（"卖一补一"），是所有预测模型的**基准线**
- 英文叫 naive forecast，刘宝红称它是"没人帮忙"的预测——任何更复杂的模型，先要证明自己比幼稚预测更准才有价值
- 再订货点补货（用掉多少补多少）本质就是幼稚预测
- 一句话判断：**"有时候，不预测就是最好的预测"**

## 详细内容

### 计算公式

> 📌 来源事实（刘宝红《需求预测和库存计划》）

**无季节性的朴素版**——下期预测 = 上期实际值：

```
F(t+1) = X(t)
```

- `F(t+1)`：第 t+1 期预测
- `X(t)`：第 t 期实际需求

**有季节性的朴素版**——下期预测 = 上年同期的实际值（m = 季节周期长度，如按季 m=4、按月 m=12）：

```
F(t+1) = X(t+1−m)
```

### 实际算例（无季节性）

> 💡 LLM 算例（演示数据，非库内真实销量）

某 SKU 连续 6 周销量 `90, 110, 85, 120, 95, 105`，用幼稚预测：

| 周 | 实际销量 X | 预测 F | 误差（实际−预测） |
|----|-----------|--------|------------------|
| 1  | 90        | —      | —                |
| 2  | 110       | 90     | +20              |
| 3  | 85        | 110    | −25              |
| 4  | 120       | 85     | +35              |
| 5  | 95        | 120    | −25              |
| 6  | 105       | 95     | +10              |
| 7  | —         | 105    | —                |

**第 7 周预测 = 105**（直接照搬第 6 周实际值）。

均方误差（MSE）：

```
MSE = [(110−90)² + (85−110)² + (120−85)² + (95−120)² + (105−95)²] / 5
    = (400 + 625 + 1225 + 625 + 100) / 5
    = 2975 / 5 = 595
```

### 季节性朴素预测算例

> 💡 LLM 算例（演示数据）

某季节款去年 4 个季度销量：春季 2000、夏季 3500、秋季 3000、冬季 1500。若不做任何趋势修正，今年各季的朴素预测就是**直接沿用去年同期**：

| 季度 | 今年预测 |
|------|----------|
| 春季 | 2000     |
| 夏季 | 3500     |
| 秋季 | 3000     |
| 冬季 | 1500     |

> 若业务整体在增长，这种"照搬去年同期"会系统性偏低，需要叠加趋势修正（见 [[wiki/供应链管理/预测方法/霍尔特-温特法]]）。

## 适用与要点

| 项目 | 说明 |
|------|------|
| **适用** | 短期、颗粒度小（门店/分仓补货）、补货周期极短、需求波动大到没法建模 |
| **本质** | "卖一补一"；再订货点补货就是它的落地 |
| **角色** | 一切模型的**基准线**——复杂模型先证明自己比它强才有意义 |
| **陷阱** | 有趋势/季节时永远"慢一拍"、被动跟随；颗粒度大、周期长时不可靠 |

> 📌 来源事实：刘宝红反复强调——在门店、客户层面做预测本身就难，加上预测者的系统性偏见（如销售"提需求"习惯性虚高），往往**还不如不预测**，直接用幼稚预测；但幼稚预测要尽可能用于短期，一旦失误恢复也快。
