# 长尾产品-泊松分布法（Poisson Distribution）

> **状态**：unreviewed
> **最后更新**：2026-11-16
> **来源**：[[raw/知识文件归档/供应链管理-刘宝红/6、《需求预测和库存计划  一个实践者的角度》2020年]]、[[wiki/供应链管理/SOP方法与刘宝红计划方法对比]]

## 核心要点

- **长尾产品**（低频、零散出单的 SKU）需求不满足正态分布，**用泊松分布模拟更准确**
- 泊松只用一个参数 λ（平均需求率），且**均值 = 方差 = λ**；取值从 0 开始，符合"销量不能为负"的现实
- 用途：算"某一期需求 = k 件"的概率，以及累计概率 → 定**再订货点 / 安全库存**、对应目标有货率
- 对长尾 SKU，往往"卖一补一（幼稚预测）+ 少量安全库存"的**简单法则**反而更省，别上复杂模型

## 详细内容

### 计算公式

> 📌 来源事实（刘宝红《需求预测和库存计划》第 6 章：长尾需求用泊松分布模拟更准确）

某一期恰好卖出 k 件的概率：

```
P(X = k) = λ^k · e^(−λ) / k!      (k = 0, 1, 2, …)
```

- `λ`：平均需求率（每期平均销量）；`k!`：k 的阶乘；`e ≈ 2.71828`
- 累计概率 `P(X ≤ k)` = 需求不超过 k 件的概率 = 备 k 件库存时的**有货率**

### 实际算例（λ = 0.5 件/周）

> 💡 LLM 算例（演示数据）

某长尾 SKU 平均每 2 周卖 1 件，即 λ = 0.5 件/周。`e^(−0.5) = 0.60653`。

```
P(0) = 0.60653 × 0.5⁰/0! = 0.60653 × 1       = 0.6065
P(1) = 0.60653 × 0.5¹/1! = 0.60653 × 0.5     = 0.3033
P(2) = 0.60653 × 0.5²/2! = 0.60653 × 0.25/2  = 0.0758
P(3) = 0.60653 × 0.5³/3! = 0.60653 × 0.125/6 = 0.0126
P(4) = 0.60653 × 0.5⁴/4! = 0.60653 × 0.0625/24 = 0.0016
```

| k（本周需求） | P(X=k) 单期概率 | P(X≤k) 累计（有货率） |
|--------------|----------------|----------------------|
| 0 | 0.6065 | 0.6065 |
| 1 | 0.3033 | 0.9098 |
| 2 | 0.0758 | 0.9856 |
| 3 | 0.0126 | 0.9983 |
| 4 | 0.0016 | 0.9998 |

**解读**：本周一件不卖的概率约 61%；卖 1 件约 30%；卖 3 件以上几乎不可能（<0.2%）。

**定再订货点 / 安全库存**（假设补货提前期 ≈ 1 周，需求就在这 1 周内发生）：

| 目标有货率 | 需备库存 |
|-----------|----------|
| 90% | 备 1 件（91% 刚够） |
| **95%** | **备 2 件**（98.6%） |
| 99% | 备 3 件（99.8%） |

> 备 1 件只有 91% 有货率，达不到 95% 目标；备 2 件就有 98.6%，多备 1 件换来 7 个百分点的确定性。

### 为什么长尾不能用正态分布

> 📌 来源事实（刘宝红）：正态分布是"钟形曲线、左右对称"，但长尾产品平均需求极低时，正态分布会预测出**负需求**（胡说），且离散的真实分布（大量 0、偶尔 1~2 件）与钟形相差甚远。泊松分布有下界 0、由单个 λ 决定形态，对低频零散出单更贴合。

### 简单法则：长尾不必上复杂模型

> 📌 来源事实（刘宝红"用简单法则来指导长尾需求的计划"）：对长尾 SKU，用"卖一补一"的幼稚预测 + 少量安全库存（如常备 1~2 件、卖完再补）往往比复杂统计模型更省、更好执行。

## 适用与要点

| 项目 | 说明 |
|------|------|
| **适用** | 低频、零散出单的长尾 SKU；正态分布不适用时 |
| **λ 怎么来** | 过去一段时间的平均每期销量（如 12 周总销量 ÷ 12） |
| **决策输出** | 由累计概率反推"备几件 = 多少有货率"，定再订货点/安全库存 |
| **简单替代** | "卖一补一 + 备 1~2 件"，省掉统计，长尾场景性价比高 |
