# 下单盘点工具表字段字典

> **状态**：unreviewed
> **最后更新**：2026-11-03
> **来源**：[[下单盘点工具表-字段字典与公式说明-2026-11-02]]（1:1 文本存档）、[[下单盘点工具表-字段字典与公式说明_v1_20261102.xlsx]]（二进制原件）
> **对应源表**：下单盘点-工具表-伟卿.xlsx（Google Sheets 导出，14 张子表，公式封装 `__xludf.DUMMYFUNCTION`，**仅线上 Google Sheets 可算**，本地打开一片 `#NAME?`）

## 核心要点

- **14 张子表 = 5 层流水线 + 主数据 + 核对区**：线上日销表/审批表（500+ 张外链）→ 网址索引（日销表网址/审批表网址）→ `0` 表（当日快照）→ **下单发货（核心引擎）** → 下单汇总 → 发货汇总；主数据层：SKU对应关系 / LISTING / 供应商表 / 箱率 / 工厂仓名称 / 船代(同步)；另有审批表核对数据（7 品类区块）与临时（人工校准粘贴区）。
- **下单/发货决策一句话**：可售天数 =（到货周预测库存 + 预入在途）÷ 日均控制销量，跌破安全库存天数（15/20/23/30 阶梯，藏在 `0` 表 N 列，按日销量级分档）才触发下单/发货。
- **可售天数有两条口径**（两个计算器各看各的到货周）：下单口径 S 列锚 O 列（下单的货到仓那周）；发货口径 AC 列锚 Z 列（本周一+船期+发货间隔 6 天 = 发货的货到仓那周）。
- **AC 是因、AG 是果**：AC 不含本周新填的计划发货量；AG = `IF(AC>I, 0, (I−AC)×AA+AF)` 由 AC 推出，填进日销表后下周才回流进分子（已发→进 AB，未入库→留在 AD 被扣）。周循环。
- **审批表核对数据 = 三道守恒闸**：待生产池 / 在途池 / 库存总池各一道，"上周填报 + 上周动作"应能精确推出"本周填报"，推不平就报警。
- 13 条坑点全表详见 raw 存档 `07坑点清单`；最致命三条：①公式仅线上可算（本地是死快照）②单 sheet 636 万单元格导致 Excel 打不开 ③表头与内容错位（K3 写"工厂"实为交期）。

## 详细内容

### 引擎「下单发货」的参数区（第 2 行 = 整表时钟）

```
A2 = TODAY()-WEEKDAY(TODAY(),2)+1   → 本周一
B2 = A2+21                          → 发货日（下单后 3 周）
C2 = A2-7 / D2 = A2-1               → 销量起点 / 库存截止
E2/F2 = 人工填：过年船期影响 / 交期影响
```

### 下单口径（左半区）关键公式

| 列 | 逻辑 |
|---|---|
| N | 下单日+交期 → 归下个周一（到货周锚 O 的上游） |
| O | N+船期 → 归下个周一 = **下单的货到仓那周** |
| P | 到货周起安全库存天数内的平均控制销量（IMPORTRANGE+QUERY，剔唯一峰值防刷单） |
| Q | 到货那天（O 日）的预测库存 |
| R | 备注里日期>O 的"预入N"合计（未来在途） |
| S | **可售天数 = ROUND((Q+R)/P)** |
| W/X | 下单量(14天)=本次下单到货周连续14天控销之和；下单量(补足库存)=本周库存与安全库存差额+正常补14天销量：`IF(S>I,0,(I−S)×P+W)` |

### 发货口径（右半区）关键公式

| 列 | 逻辑 |
|---|---|
| Z | `$B$2+J4+Y4` 归周一 = **发货的货到仓那周**（整条链的时点锚） |
| AB | Z 日预测库存（QUERY 日销表 Col11） |
| AD | 发货到货周之前未入库的数量（业务口径：已发货的在途+未生产批次；公式筛选=备注含 预入/待生产、非截单、日期≤Z）→ 从预测库存中扣掉防双算 |
| AC | **可售天数 = ROUND((AB−AD)/AA)** —— 锚到货周而非发货周（发货当下仓必有货，风险在海上空档） |
| AG | `IF(AC>I, 0, (I−AC)×AA+AF)` 补足库存口径发货量 |

### 字段白话口径（业务方 2026-11-03 定稿）

| 字段 | 业务口径 |
|---|---|
| F 下单预估 / G 发货预估 | 本周下单量 / 本周计划发货 与在库在途总库存的可售天数（= 本周预下单 / 预发货的库存量 ÷ 控制日销） |
| R / U 该周后、下周后下单量 | 本周后 / 下周后还有多少到 FBA 仓的预入量（应叫「预入库量」） |
| W 下单量(14天) | 本次下单到货周的连续 14 天控销之和 |
| X 下单量(补足库存) | 本周库存与安全库存的差额 + 正常补 14 天销量 |
| AD 发货时间前未发货订单 | 发货到货周之前未入库的数量（已发货的在途） |
| AE 第一票 | 首单已发货未入库的数量 |
| AF 发货量(14天) | 到货周周一前 6 天和后 8 天的控销之和（公式区间 Z−6 ~ Z+8） |
| AG 发货量(补足库存) | 在库库存的可售天数补到安全库存 + 正常发货量 |

### 审批表核对数据 — 三道守恒闸（鞋架块 W1:AK5 为例）

同一 SKU 相邻两行：上行=本周一填报、下行=上周一填报，核对即两行对账。

| 闸 | 守恒式 | 对平标准 | 报警含义 |
|---|---|---|---|
| AH 待生产 | 本周待生产 −(上周待生产+上周可下单−上周可发货) | = 0 | 漏登记新下单 / 截单没记录 |
| AI 截单 | (上周FBA+AWD+在途+可发货 − 本周FBA+AWD+在途) ÷ 实际日销 | ≈ 7 天 | 缩水远超一周销量 = 多出的部分去向不明（截单/漏填）；日销<1 退回件数 |
| AK 在途 | 本周在途 −(上周在途+上周可发货−FBA增量−日销×7) | = 0 | 海运池不平；孤立行标"新品"，断行吐"检查" |

- **截单是唯一"非法出口"**：截在生产段 → AH 报警（AI/AK 正常）；货在海上被取消/漏填 → AK 报警 + AI 折算天数异常。
- 第四道小闸 AJ「AWD差」= 本周 AWD 填报 − 备注"预补N"合计（独立口径核对）。
- 重名陷阱：原始区 AD/AE 也叫"在途/待生产"（填报数量），核对区 AH/AK 同名但值是**对账差额**，=0 才正常。

### 坑点 Top 5（全 13 条见 raw 存档）

1. 全部公式仅 Google Sheets 可算，本地文件只是死快照
2. 审批表核对数据单 sheet 636 万单元格（147MB XML），Excel 打不开的元凶
3. 表头与内容错位：K3"工厂"实为交期、L3"供应商"实为工厂名
4. 硬编码遍地：M=14 天、Y=6 天、B2=A2+21、DATE(2026,8,2)
5. 文本型数字：导 Excel 后 SUM 把文本当 0，核对列静默失真
