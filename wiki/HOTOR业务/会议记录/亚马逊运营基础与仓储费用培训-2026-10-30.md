# 导师培训纪要：亚马逊运营基础 + 仓储费用（2026-10-30）

> **状态**：unreviewed
> **最后更新**：2026-10-30
> **来源**：[[raw/知识文件归档/HOTOR业务/会议记录/亚马逊运营基础与仓储费用培训/原文_亚马逊运营基础与仓储费用培训]]（语音转写，未经校读）
> **性质**：导师对计划岗新人的培训。两块内容：① 亚马逊运营基础名词（listing / 关键词 / 星级 / 促销 / 流量）；② 与计划岗相关的仓储费用。约 72 分钟。

## 核心要点

- **关键词三档**：核心关键词（流量最大的 1–2 个词）→ 中长尾词（流量大、更具体）→ 长尾词（场景化、流量小）；未来 AI 可能直接匹配「需求场景」而非词。
- **星级是计划关注的硬指标**：4.8–4.3 = 四星半、4.3–3.8 = 四星；**四星半以下流量骤减**（例：4.3 星销量 500 → 4.3 以下骤降到 50 甚至 5）；日本站特殊（四星即可撑住）。
- **流量漏斗**：曝光 → 点击 → 加购 → 购买 → 售后/复购，每个环节都有转化率。
- **促销两大主力**：LD（限时秒杀，12h 影响短期）+ BD（7–14 天秒杀，可按天收费，影响打底 14 天）；PD（会员日）+ 黑五网一是流量最大的两个固定大促；coupon（CP 优惠券）最常用。
- **费用是补货的硬约束**：旺季（10/15–1/15）仓储费约 **3 倍**；超龄库存费美国 **181 天起收、阶段累加、271 天以上翻约 8 倍**；低库存水平费美/加 **28 天**、英/日 **14 天**；入库配置费分仓后**各票入库时间差 ≤30 天**否则五票全收。
- **AWD 越用越少、AGL 有成本优势**：AWD（官方仓储分拨）不限库容/低库存费但无贴标、曾爆仓；AGL（官方物流）成本/凑柜优势 vs 三方快且稳。

## 详细内容

### 一、运营基础名词

- **FBA / FBM**：自配送（FBM）发货，FBA 交亚马逊（不再展开）。
- **ASIN / Listing / 主图 / 五点描述**：listing = 详情页；主图 = 搜索页第一张图；五点描述 = 详情页 5 个产品特点，要**埋词**（写词有方法，与 SEO/转化率相关）。
- **关键词三档**：
  - **核心关键词**：流量最大的 1–2 个词（如 `desk`）。
  - **中长尾词**：流量大、更具体（如 `desk for kitchen` / `desk for living room`）。
  - **长尾词**：场景化、更具体、流量小（如 `desk for living room with three people`）。
  - 搜索与转化相关性：埋的相关词越多、相关性越高；推广端会查重限制，有埋词方法。
  - **AI 影响**：未来搜索引擎可能直接匹配 AI 的「需求场景」而非关键词，但目前无统一模式。
- **Best Seller（品类第一）**：对计划是「产品定位」信号——冲第一 vs 中部的销量有梯队差异，计划只关注「第一 vs 中部」。
- **A+ 页面 / MCF**：A+ = 详情页图文描述（不细关注）；MCF 多渠道配送 = 用 FBA 产品发其他平台/自发货（偶尔海外仓/多平台不够时用，配送费贵）。

### 二、Buy Box 与跟卖 / 透明计划

- **跟卖**：一条 ASIN 可有多个卖家挂库存，10 个店铺可跟卖同一条链接，产生「抢购物车」。
- **抢购物车**：取决于亚马逊算法（千人千面），**价格是最大权重**，其次仓库点位（库存就近匹配，如纽约买家更匹配纽约/加州库存）。
- **透明计划 + 品牌的由来**：早期无限制，其他卖家可跟卖 best seller 链接，恶意改价格（如 30 → 20，购物车被抢）、改详情、发空包、做差评（深圳莆田卖家恶搞）；透明计划=防伪处理。
- **review 两维度**：`rating`（星级）+ 评论。星级影响推广流量，计划**只要懂大星级区间**；推广/产品/质检关注评论与退货率。

### 三、星级区间（计划关注）

- 4.8–4.3 = **四星半**；4.3–3.8 = **四星**。
- **四星半以下是公司的红线**：流量直接骤减（4.3 星销量 500 → 4.3 以下 50 甚至 5），差非常多。
- 例外：**日本站**对质量要求极高、品类普遍做不到四星半（大家都是四星）；**电器类**普遍星级偏低（美国站四星也撑得住）。
- 计划的实际用法：关注大致星级 + 边界星级（如新品从五星掉到 4.3 → 要有备货防范意识，后期不激进备货）。

### 四、流量漏斗与流量来源

- **漏斗**：曝光（浏览一次）→ 点击 → 加购 → 购买 → 售后/复购（复购含售后影响）。
- **流量来源**：自然流量（自然位，没打广告自己跑出来）、广告流量（CPC 付费点击，点一次收一次费，从自然位点不收费）、促销流量、站外流量（现在做得少、效果不明显）。
- 新品通常先打广告位 → 广告位高了才形成自然位。

### 五、促销类型

| 类型 | 内部叫法 | 说明 |
|------|---------|------|
| **LD** | 限时秒杀 / 闪电促销 | limited time deal，12h 表现，影响不了长期链接表现 |
| **BD** | 周期秒杀 | 7–14 天，现在可按天收费（最高 14 天，费用随销售额走）；可影响打底 14 天，BD + 常规促销 + BD 可长期把链接做好 |
| **PD** | 会员日 | Prime Day，6–7 月，流量最大的固定大促之一 |
| **黑五网一** | 黑五 + 网一 | 流量最大的两个固定大促（另衍生春季/秋季促销，流量不如这两个） |
| **DOTD** | — | Deal of the Day，很少做（优惠要求高、链接要求高，没必要牺牲利润） |
| **coupon（CP）** | 优惠券 | 折扣促销，公司最常用；分 coupon / promote 两类 |

- 对计划影响最大的促销一般是 **LD / BD / coupon**（做控销、需求评估、下单评估时）。
- 季节性促销（如厨具、家居收纳 12–1 月合家欢旺季、9 月美国返校季）跟品类相关。

### 六、标签与排行榜

- **绿标**：亚马逊环保标（能源之星等），有流量加成、买家偏好。
- **降价标签**：先刷高参考价（如 100 卖 9 天出单）再降到 80（降幅>10–15% 出降价标）；新品上架推广端的常用操作。
- **排行榜**：BSR（best seller rank，第一有额外流量加成，抢第一名的原因）、新品榜第一、品类第一；综合算法但以销量为主。
- 黑五/PD 促销期会形成对应排行榜/促销页面，有额外流量。

### 七、界面操作与账号（要点）

- **紫鸟浏览器**：店铺登录入口，至少 2–3 个店铺；**账号关联红线**：店铺信息（邮箱等）绝不能跨店铺混发（如安格邮箱发到里里外外），否则触发关联。
- **领星（ERP）**：计划关注的界面是「供应链 › 管理亚马逊库存 / 管理货件 / Amazon 物流」；领星与紫鸟权限**各自单独配置**；数据传输是 **API 授权**问题（亚马逊没给授权的报表就传不过来）。
- **群晖共享盘**：局域网概念（内网），离公司网络不可用；与「翻墙」是同类内网/外网 IP 概念。

### 八、仓储相关费用（计划重点）

**1. 月度仓储费**：按体积/重量/尺寸分段计算，标准件非旺季约 **0.78**；大件尺寸收费标准不同；公司重心今年/明年从标准件转向大件。
**2. 仓储利用率附加费**：店铺维度的库存周转率；常规老店铺约 **6.3 周**（在库 42–45 天），一般 <22 周（第一档，不用管）；新店铺前期只发不卖、利用率会偏高。
**3. 旺季仓储费**：旺季 = 10/15–1/15（计算周期往后推半个月）；仓储费约为非旺季的 **3 倍**（非旺季 2% 多 → 旺季 3–4%，占销售额比）；所以 1–9 月可微激进备货、10–12 月要控。
**4. 物流配送费（末端 FBA 配送费）**：按尺寸分段，推广端测算关注，跟计划无直接关系（只关心产品的体积/重量/尺寸分段）。
**5. 超龄库存费（超龄库存附加费）**：美国 **181 天起收**，在 0.78 基础上额外加 0.5 起、阶段累加；**271 天以上直接加 5 倍多**（仓储费翻约 8 倍）；欧洲约 210 天、中东约 270 天；**公司统一按 180 天管理**。计划要评审推广端的「利润兜得住还能放」方案（评估量级 + 处理时间）。
**6. 低库存水平费**：美/加 **28 天**、英/日 **14 天**；取「最低/最高」两者最高值收。我们 FBA 在库天数打底 20–30 天，14 天难触发，故英/日基本不管；欧盟仅开启泛欧才收（我们未开）。
**7. 入库缺陷费**：① 入库偏差（常因亚马逊原因，需申诉追回）；② 物流缺陷——国际货件须 **75 天（现可能 90 天）内入仓**，超时收（台风/罢工/AGL 抢柜排后等都可能导致，申诉不一定成功，目前只有美国收）。
**8. 入库配置费（分仓）**：亚马逊要求分仓，**分五仓不收费、分一仓多收费**；但分仓后各票**入库时间差 ≤30 天**，超 30 天「五票全收」入库确认费（海关查验 7–14 天 + 路上十几到二十天，很极限）。计划做入库计划时要测算「发单点还是拆仓、选 AGL 还是三方」。
**9. AWD**：亚马逊官方仓储分拨中心（类似海外仓但做不了贴标）；不限库容、不限低库存水平费、可自动补货；但曾爆仓、处理费高、周转问题多，卖家越用越少。
**10. AGL**：亚马逊官方物流渠道，成本/凑柜有优势，但抢柜能力比三方差、易无限期往后排；三方快且稳。
