# 公司业务架构

> **状态**：unreviewed
> **最后更新**：2026-10-28
> **来源**：[[raw/知识文件归档/HOTOR业务/跨境电商公司业务架构与计划部职能介绍]]（负责人向新人介绍业务的逐字稿，语音转写未校读）

## 核心要点

- **四大块**：品类线（产品线）→ 业务线（平台）→ 站点（国家战略）→ 六大事业部，逐层从"卖什么"到"谁负责"
- **业务基本盘是亚马逊**：亚马逊占整体业务 **80%–90%**，公司最早亚马逊出身；其他平台都是亚马逊之后再拓展
- **品类从车载起家**：车载配件（美国车多、替换率高）→ 箱包 → 宠物 → 家居收纳 → 一次性派对 → 运动户外，日化除湿是老品类之一
- **六大事业部**：理想 / 日益 / 无双 / 长风 / 星火 / 未来，命名与分工均来自语音转写，**需人工核对**

## 详细内容

### 1. 品类线（产品线）

（来源：[[raw/知识文件归档/HOTOR业务/跨境电商公司业务架构与计划部职能介绍]] 00:22–05:18）

| 品类 | 定位 | 具体举例 |
|------|------|---------|
| 车载 | **最早起家品类**（美国几乎人人有车，配件替换率高） | 车载配件 |
| 箱包 | 近期后拓，源自车载收纳，独立后做仿制类非时尚包 | 旅行包、手提包、午餐包 |
| 宠物 | 这两年新拓（国内外宠物精神需求上升） | 狗尿垫、猫砂盆、狗笼 |
| 日化除湿 | 老品类，复购率高 | 除湿袋、除湿片；洁厕灵、蓝泡泡；曾做洗衣片、除湿机 |
| 家居收纳 | **公司非常大的品类**，分厨房/浴室/收纳家居 | 货架、浴室架、沥水架（转写"丽水家"）、晒衣架 |
| 一次性/派对类 | 补充品类 | 一次性盘子、桌布、餐具 |
| 运动户外 | 疫情后近期拓展 | 露营车（趋淘汰）→ 折叠椅、折叠桌 |

> 💡 **LLM 推断**：文中多次提到「十大战略品类」，但只点名了「丽水家」（疑为"沥水架"）、桌布等少数几个，完整清单尚未在本次逐字稿中出现，需后续补全。

### 2. 业务线（平台）

（来源：同前 06:01–11:13）

| 平台/渠道 | 定位 |
|-----------|------|
| **亚马逊** | **核心主战场，占 80%–90%**；FBA 为主，大件才走 FBM（一件代发） |
| 沃尔玛 | 第二个拓展的平台（与亚马逊相近，美国为主），建议走平台仓 WFS |
| 日本乐天 | 有一点业务，体量比沃尔玛小 |
| Temu（海外版拼多多） | 低价/一件代发为主，走海外仓自行发货 |
| TikTok（内容电商） | 需靠内容引流，走一件代发+海外仓；全托管偏贵、仓点不成熟 |
| 线下 to B | 近期考虑：直接卖给沃尔玛线下（沃尔玛自营），不自己开门店 |
| 中东平台 | 在拓展，平台名未听清（待确认） |

**曾尝试但未做大**：速卖通、阿里巴巴国际站——转写稿为"富麦通 / 阿里巴巴国际站"，原话大意是当时不够专注、集中一个力去打，故暂未重点投入。另有衍生品牌"VFL"（转写不确定）。

> 💡 **LLM 推断**：转写"富麦通"按语境应为**速卖通（AliExpress）**；"TK/特姆/拼多多海外版"即 **TikTok 与 Temu**；中东平台按语境疑为 **Noon**。以上均为基于语境的推测，未经确认。

### 3. 站点（国家战略）

（来源：同前 11:13–17:25）

主战场亚马逊，策略是"**先亚马逊、再其他平台**"，按大区域分大站：

| 区域 | 站点 | 状态 |
|------|------|------|
| 北美 | 美国 | **核心出发点** |
| 北美 | 加拿大、墨西哥 | 在做 |
| 北美 | 巴西 | 未来考虑，暂未做（消费力可以但市场不稳定） |
| 欧洲 | 英、德、法、意、西 | 在做（英国已脱欧但仍归欧洲大站） |
| 欧洲 | 爱尔兰、波兰、瑞典、芬兰等 | 待定 |
| 中东 | 沙特、阿联酋 | 在做（主要这两个大国） |
| 大洋洲 | 澳洲 | 在做 |
| 亚洲 | 日本 | 在做 |
| 东南亚 | Shopee | **暂未做**（零元购/退货风险高，且亚马逊在当地本就不大） |

### 4. 六大事业部

（来源：同前 17:25–31:43）

> ⚠️ 事业部名称「理想 / 日益 / 无双 / 长风 / 星火 / 未来」均为语音转写，**读音可能有误，需人工核对**。分工与演变逻辑清晰，但个别名字不可直接引用。

| 事业部 | 由来 | 负责品类/范围 |
|--------|------|--------------|
| **理想** | 最早的事业部，最早品牌为 auto | 车载 + 箱包 + 宠物（为主），少量户外 |
| **日益** | 老事业部，日化除湿起家 | 除湿/绿化类 + 一次性派对类（为主），少部分户外/宠物；曾做除湿机等电器 |
| **无双** | 这两年新建（先有无双、后有长风） | 收纳为主：货架、鞋架、浴室架、临时架（零食架/玩具架/植物架等，部分在开发中） |
| **长风** | 去年刚成立 | 收纳类（厨房收纳 Kitchen 超大品类）：晒衣架、马桶置物架、厕所架等 |
| **星火** | 孵化部门（"星星之火可以燎原"），今年战略调整 | 负责**中小战略站点**：欧洲站 + 加拿大 + 日本，覆盖所有品类 |
| **未来** | 原核心品类吸尘器（曾有一两亿规模）受"黑科技/刷单"查品牌影响，转型 | 拓展事业部：沃尔玛等多品牌系列、除亚马逊外渠道（Temu、TikTok 等）、澳洲、中东、新拓品类 |

> 📌 **事业部逻辑变化**：以前按品牌区分事业部（十几个品牌，主力品牌 auto），现在品牌之间有交叉，不再严格按品类锁死——否则会限制事业部的拓展与业绩空间，改为"基本品类为主 + 少量交叉"。
