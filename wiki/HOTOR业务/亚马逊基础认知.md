# 亚马逊基础认知

> **状态**：unreviewed
> **最后更新**：2026-10-30
> **来源**：[[wiki/HOTOR业务/计划运营SOP课程存档]] 之「亚马逊基础认知」组，8 篇原文 + [[raw/知识文件归档/Daily/2026-10-28]] 导师口述补充 + [[raw/知识文件归档/HOTOR业务/会议记录/亚马逊运营基础与仓储费用培训/原文_亚马逊运营基础与仓储费用培训]]（2026-10-30 培训）

## 核心要点

- **Listing 七要素**：标题、五点描述、商品描述、商品图片、搜索关键词、A+ 页面、分类节点——全部影响搜索权重
- **费用结构是做库存计划的底层约束**：低库存会触发「低库存水平费」，压货会触发「超龄库存费（≥181 天）」
- **SKU / ASIN / MSKU / FNSKU 是四套不同口径的编号**（其上还有 SPU，其下还有透明计划码），采购计划下单时要求 AK 产品管理的 SKU 与后台 MSKU 配对关联
- 违规分四类（产品合规 / 账号合规 / 运营行为 / 交易履约），申诉统一走 **POA 整改计划**

### 2. 常见术语（五类）

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/亚马逊常见术语有哪些？]]）

原文按 **① 商品识别类 ② 产品页面 ③ 物流 ④ 广告 & 秒杀 ⑤ 绩效** 五组列词。日常沟通中最高频混淆的是 UPC / EAN / GCID 这组「商品识别 ID」，以及在办理透明计划、GTIN 豁免时的口径差异。

**商品编码（GTIN 体系）辨析**：

「EAN / UPC / ISBN / GTIN」不是单独某一种条码，而是 GS1 体系里**几种一维商品编码的统称标签**：

- **GTIN（Global Trade Item Number，全球贸易项目代码）**：是顶层统称，EAN、UPC、新版 ISBN 本质都属于 GTIN 的一种格式。
- **UPC（GTIN-12）**：12 位，北美主流零售条码。
- **EAN（GTIN-13 / EAN-13）**：13 位，全球（含国内 69 开头）最常用商品条码；还有短款 EAN-8。
- **ISBN（GTIN-13）**：图书专用编码，现在新版 ISBN 就是 13 位 EAN 条码格式。

简单理解：**GTIN 是编号体系，EAN/UPC/ISBN 是它的不同应用形态，都用同一种 EAN/UPC 一维条码符号打印出来**，亚马逊等跨境平台经常会写这个字段用来填商品编码。

**SKU / MSKU / FNSKU / 透明计划 层级辨析**（来源：[[raw/知识文件归档/HOTOR业务/跨境电商公司业务架构与计划部职能介绍]]，负责人口述）：

从大到小：**SPU → SKU → MSKU → ASIN → FNSKU → 透明计划码**

- **SPU**：最上层产品单元（口述未展开）
- **SKU**：公司内部编码（我们自己的命名）
- **MSKU**：亚马逊平台对商品的命名，一个 SKU 可建多个 MSKU，但链接通常只有一条
- **ASIN**：商品链接（各平台有各自的命名方式）
- **FNSKU**：亚马逊仓储端识别库存的单位（库存标签），同批次可贴同码
- **透明计划码**：比 FNSKU 更小一级，**一物一码**（每件贴不同码），防跟卖；入库时与 FNSKU 同一环节管理
- **关联动作**：下单时需在 ERP 上把内部 SKU 与后台 MSKU 配对关联
- **SKU 命名规律**（来源：[[raw/知识文件归档/Daily/2026-10-28]]，导师口述）：国家缩写（US 等）是历史遗留（早前以美国为主、按国家单独开发产品），现全站点开发、SKU 不再带国家（仅 MSKU 由平台站点带国家识别码）；SKU 后半段 = 产品规格，通常只含**重点三属性**（如 `NRP0ZB001-6-BL-L` = 数量、颜色、尺寸）

### 3. 后台菜单栏地图

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/亚马逊操作界面后台介绍]]）

**目录（Catalog）** 下七个高频入口：

| 入口 | 用途 |
|------|------|
| 添加商品 | 创建 Listing，填标题/价格/库存/图片 |
| 批量上传商品 | Excel/CSV 模板批量上架，SKU 多时用 |
| 添加尺码表 | 服装鞋类尺码信息 |
| 补全您的草稿 | 继续编辑未完成的 Listing 草稿 |
| 查看销售申请 | 受限类目/品牌的销售许可进度 |
| Upload Images | 上传/替换主图与辅图 |
| 上传和管理视频 | 详情页视频，提升转化 |

**库存（Inventory）** 下三个一级入口：管理所有库存（在售 SKU 的库存、价格、批量上下架）、管理卖家自配送商品（FBM）、Sell Globally（开通欧洲/日本/澳洲等站点）。

### 4. Listing 七要素与变体

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/亚马逊listing介绍]]）

| 要素 | 原文口径 |
|------|---------|
| 标题 Title | 品牌名 + 产品名 + 特征/型号；**亚马逊站内外最重要的搜索项** |
| 商品要点 Bullet Point | 最多 5 条，即「五点描述」 |
| 商品描述 | 详细文本说明 |
| 商品图片 | 主图（Main Image）显示在搜索结果页；辅图补充角度与细节 |
| 搜索关键词 Search Term | 与买家搜索词匹配；文本匹配度 + 价格 + 供货 + 销售历史共同决定排名 |
| A+ 页面 | 图文组合的商品描述，提高转化 |
| 分类节点 Browse Node | 分类终端节点，决定买家浏览路径 |

**变体（Variation）**：即父子体关系，允许买家在单个详情页按颜色 / 尺寸 / 数量对比选择。

### 5. 费用结构（六类）

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/亚马逊相关费用介绍]]）

| 费用 | 触发条件（原文口径） |
|------|-------------------|
| 月度仓储费 | 按日均占用体积（立方英尺）计；含基本费 + **仓储利用率附加费** |
| 物流配送费 | 按件收，因分类 / 尺寸 / 重量而异 |
| 超龄库存费 | 在亚马逊配送网络存放 **181 天及以上**（原长期仓储费） |
| 低库存水平费 | 长期（90 天）与短期（30 天）**历史供货天数均少于 28 天**才收；仅短期<28天则不收 |
| 入库缺陷费 | 货件配送至错误运营中心；国内货件 45 天 / 国际货件 75 天未送达；多目的地计划中其余货件未在首票送达后 30 天内送达 |
| 入库配置费 | 随亚马逊拆货方式变动，是货运周期的不确定项之一（参见 [[wiki/HOTOR业务/计划与供应链SOP]]） |

> 💡 **LLM 推断**：低库存水平费与超龄库存费一前一后夹住库存水位（<28 天补货不足、>181 天压货），这两个阈值共同决定了补货数量的合理区间，建议在《发货计划SOP》与《检查配送费／库龄操作指南》之间做交叉引用——两份原文各自只提一侧。

> 📝 **培训补充（2026-10-30，来源：[[raw/知识文件归档/HOTOR业务/会议记录/亚马逊运营基础与仓储费用培训/原文_亚马逊运营基础与仓储费用培训]]，未校读）**：
> - **旺季仓储费约为 3 倍**：旺季 = 10/15–1/15；非旺季费率 2% 多 → 旺季 3–4%（占销售额比）。故 1–9 月可微激进备货、10–12 月要控库存。
> - **超龄库存费美国 181 天起收、阶段累加**，271 天以上额外加约 5 倍（仓储费翻约 8 倍）；欧洲约 210 天、中东约 270 天；公司统一按 180 天管理。
> - **低库存水平费**：美/加 28 天、英/日 14 天，取最低/最高两者最高值；我司 FBA 在库天数打底 20–30 天，14 天难触发。
> - **入库缺陷费**：入库偏差 + 物流缺陷（国际货件 75 天、现可能 90 天内入仓限制）。
> - **入库配置费（分仓）**：分五仓免费、分一仓多收；分仓后各票入库时间差 ≤30 天，超 30 天五票全收。
> - **AWD**（官方仓储分拨，不限库容/低库存费但无贴标、曾爆仓、越用越少）与 **AGL**（官方物流，成本/凑柜优势 vs 三方快且稳）是补货渠道决策的两个变量。

### 8. 违规类型与申诉

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/亚马逊主要违规类型]]）

四类违规：

| 类别 | 典型行为 |
|------|---------|
| 产品合规违规 | 侵权（商标/专利/版权）、禁售品、未达安全标准（CE/FCC/CPSC） |
| 账号合规违规 | 多账号关联（违反「一人一店」）、注册信息虚假、未通过 KYC/二审 |
| 运营行为违规 | 虚假评论、滥用关键词（标题堆砌 / 蹭竞品品牌词）、虚假促销、恶意篡改 Listing 抢占购物车 |
| 交易与履约违规 | 延迟/未发货、ODR 超标、虚假物流单号、拒绝合理退换货 |

**申诉链路**（原文原文顺序）：平台检测/用户举报 → 亚马逊发绩效通知 → 卖家提交 **POA（Plan of Action）** + 发票/授权书/物流凭证 → 审核通过恢复权限，不通过则继续限制或封号。

申诉覆盖范围详见 [[wiki/HOTOR业务/亚马逊合规与风控]]。

### 9. Buy Box（黄金购物车）逻辑

（来源：[[raw/知识文件归档/Daily/2026-10-28]]，导师口述）

- **同 ASIN 多卖家竞争一个成交入口**：一条 ASIN 是公开的，有同类产品的卖家都能挂库存，但订单归**当前购物车（Buy Box）占有者**，只有占了购物车才会在详情页单独显示购买入口。
- **上购物车的两个前提**：**有库存 + 已开售**；链接若设置时间无特殊调整，可正常在详情页显示——「Listing 显示」与「购物车」是两回事。
- **黄金购物车（优先购买框）**：基于库存维度存在**隐藏的显示逻辑，千人千面**。影响因素中**价格占比最大**，其次发货时效（库存仓库所在地远近，FBA 更快）、店铺账号表现。
- **运营端正当动作**：管好价格、发货方式（FBA 更快）、账号表现去争取/保住 Buy Box；**不得用篡改 Listing 等恶意手段抢占**（属运营行为违规，见本页第 8 节）。

> 关联：抢 Buy Box 的完整答疑记录见 [[计划岗答疑纪要-2026-10-28]] 第 2 节。

### 10. 运营推广名词与促销（2026-10-30 培训补充）

（来源：[[raw/知识文件归档/HOTOR业务/会议记录/亚马逊运营基础与仓储费用培训/原文_亚马逊运营基础与仓储费用培训]]，未校读）

- **关键词三档**：核心关键词（流量最大的 1–2 词）→ 中长尾词（流量大、更具体）→ 长尾词（场景化、流量小）；未来 AI 可能直接匹配「需求场景」而非词。
- **星级区间**：4.8–4.3 = 四星半、4.3–3.8 = 四星；四星半以下流量骤减；日本站（四星即可撑住）、电器类（普遍偏低）例外。计划只关注大星级区间 + 边界星级（新品五星掉到 4.3 要防范）。
- **流量漏斗**：曝光 → 点击 → 加购 → 购买 → 售后/复购；流量来源分自然 / 广告（CPC 付费点击）/ 促销 / 站外。
- **促销主力**：LD（限时秒杀，12h）+ BD（7–14 天，可按天收费）+ PD（会员日）+ 黑五网一 + coupon（CP 优惠券，最常用）；DOTD 很少做。
- **标签/排行榜**：绿标（环保标）、降价标签（先刷参考价再降 >10–15%）、BSR（best seller 第一有流量加成，销量为主综合算法）。
- 完整促销/流量/费用明细见 [[wiki/HOTOR业务/会议记录/亚马逊运营基础与仓储费用培训-2026-10-30]]。
