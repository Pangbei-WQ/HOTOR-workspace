# 亚马逊后台操作SOP

> **状态**：unreviewed
> **最后更新**：2026-10-27
> **来源**：[[wiki/HOTOR业务/计划运营SOP课程存档]] 之「后台操作 SOP」组，9 篇原文 + 1 份工具台账

## 核心要点

- **不可售库存一个月处理两次**：每月 5 日和 20 日亚马逊自动批量清货/退货，须在这两个日期**之前**完成——先紫鸟后台清货，再 AK 系统弃置
- **货件差异索赔有门槛**：近三个月、状态 CLOSED、收发差异「签收量<发货量」，且**差异 ≥30 件**才值得发起调查
- **开 CASE 有账号隔离红线**：电话等关联信息只能提供该店铺的，禁止跨店混用，否则触发账号关联
- **部分更新走模板**：删链接、改开售日期、改尺寸统一用「库存加载工具 + 部分更新模板」，不走编辑页

### 1. 新品 / 新变体建单与跟卖

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/亚马逊新品／新变体建单和跟卖SOP]]，本组最长文档 33 KB）

三条主线：

1. **建单前准备** → **方法一：手动建单**（空白表单逐个上传）→ **方法二：批量建单**（电子表格上传）
2. **UPC 豁免流程**：原文给出豁免定义、为什么需要、申请条件
3. **跟卖**：接入已有 Listing

> 📌 岗位边界（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/采购计划下单SOP]]）：**新品 AK 建单由开发运营负责；后台 MSKU（Listing）建单由项目运营负责。**

### 2. 开 CASE

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/亚马逊后台开CASE操作SOP]]）

| | 普通版 | PSS 高级会员版 |
|---|---|---|
| 路径 | 帮助 › 获取帮助和资源 | 帮助 › 联系专员 |
| 兜底入口 | 问题不在分类里 → 点「我的问题未列出」 | — |
| 联系方式 | 邮件 / 电话 / 在线聊天 | 邮件 |

原文关键规则：

- 提交成功生成 **case id**，凭此 id 在「帮助 › 管理支持问题」查询回复
- **如需填写电话号码，须先跟余立总确认店铺电话是多少**（普通版与 PSS 版均适用）
- 部分问题在中文后台没有「电话」和「聊天」按钮，需切换英文模式；**英文客服权限更高、处理更快**
- 邮件沟通客服几小时才回，小问题可用；急事优先电话/聊天

### 3. 删除链接与更新信息（部分更新）

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/利用模板删除链接和更新信息]]）

**适用场景**：链接创建有误或多余 → 删链接；物流创建货件时产品下架或尺寸库存分配不对 → 改开售日期/尺寸。

**操作路径**：后台搜索「库存加载工具」→ 按 Data Definitions 模板填写 → 另存为**制表符分隔的 .txt** → 上传。

删除链接的四个必填字段：

```text
sku            = MSKU
product-id     = ASIN
product-id-type = 1        # 1 = ASIN
add-delete     = x         # x = completely remove from system
```

### 6. 配送费与库龄检查

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/检查配送费／库龄操作指南]]）

> 原文目的原话：「通过定期检查配送费与库龄，实现**精细化管控物流成本与库存健康度，实现利润最大化与合规运营**。」

| 检查项 | 工具（领星 AK） | 动作 |
|--------|----------------|------|
| 物流配送费 | 【销售】›【FBA费差异】 | 先维护「应收FBA费」字段；差异受低库存水平费、SIPP 计划影响 |
| 超龄库存费 | 【仓库】›【FBA库存明细】 | 导出 181–270 / 271–330 / 331–365 / 365+ 天库龄不为零的部分，**推广运营重点处理**（低价清货、清算、弃置）；91–180 天需关注 |
| 低库存水平费 | 【仓库】›【FBA库存明细】 | 导出「历史供货天数」介于 0 与 28.00 之间的 MSKU |

### 7. 货件状态查询

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/FBA货件状态查询操作流程]]）

**查 FBA 编号**：供应链计划表 › 物流发货货件表，输入采购单号（PO 单号）查；表内同时可看实际开船/到港/入仓时间与物流备注。货件到港后如需尽快入库，联系对应物流同事催货代派送。

**10 种货件状态**（原文定义）：

| 状态 | 含义要点 |
|------|---------|
| 处理中 Working | 尚在编辑，未提交确认，未进发货流程 |
| 准备发货 Ready to Ship | 已确认内容，打印箱唛、填物流信息 |
| 已发货 Shipped | 卖家手动点了「标记为已发货」，**不代表亚马逊真的收到** |
| 运输中 In Transit | 承运人已接收，轨迹自动更新 |
| 已送达 Delivered | 到仓门口，未扫描入库——处于「到仓但未处理」 |
| 已登记 Checked-In | 已扫到货件条码/预约信息，可能停留数小时至数天 |
| 正在接收 Receiving | 正在开箱、扫描、入库 |
| 已完成 Closed | 全部接收或异常处理完毕；或国内货件开放超 **45 天**、国际货件超 **75 天**自动关闭 |
| 已取消 Cancelled | 取消未发货件或系统超期自动取消，**无法恢复，只能新建** |
| 已删除 Deleted | 人为删除的废弃/测试货件 |

> ⚠️ **易混淆点**：Shipped（卖家自己点的）与 Delivered / Receiving（亚马逊实际收货）之间有明显时差，做发货计划时只有 Receiving / Closed 状态的数量才能计入可用库存。

### 8. 货件差异索赔

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/FBA货件差异索赔操作流程]]）

**第一步 · 筛选**（AK › FBA › FBA货件 › 货件看板）：店铺 + 状态 **CLOSED** + 收发差异「签收量<发货量」+ 创建时间**近三个月** → 下载文件 → 筛出**差异 ≥30** 的货件。

**第二步 · 后台调查**：搜索货件编号 › 追踪货件 › 查看物品信息 › 状态选「调查缺失商品」› 提交两个文件：

1. **装箱单**：按 PACKING LIST 模板填写，**打印签字后转成 PDF** 上传
2. **交货证明**：向建单的物流同事索取

备注诉求 › 预览请求 › 发起后生成 CASE id，跟进亚马逊调查进度。

### 9. 不可售库存的清算与弃置

（来源：[[raw/知识文件归档/亚马逊运营/计划运营SOP课程存档/FBA不可售库存的清算与弃置SOP]]）

**两类成因**：买家退货（拆封/使用/损坏/缺件/原厂包装撕毁）与 FBA 仓库操作（挤压淋湿、丢失找回）。在管理库存页点不可售数量可查具体原因。

**时间窗口**：亚马逊每月 **5 日和 20 日**自动发起批量清货与退货 ⇒ 须在这两个日期**之前**操作，**一个月两次**，顺序是先**紫鸟后台清货** → 再 **AK 系统弃置**。

**清货（Liquidation）**

- 路径：卖家后台 › 库存 › 管理所有库存 › 移除不可售商品
- 一页内能装下的点「选择全部」；数量多时翻页并选**显示 50 条**（选 100 条可能因数据量过大报错）
- 费用：**售价的 5%–10%**；限制：**每个 ASIN 每月最多清货 500 件**
- 适用条件：无侵权、非危险品、非受限商品

**弃置（Disposal）**

- 路径：AK 系统 › 统计 › 移除订单 › 添加订单 › 选择站点 › 移除类型选「销毁 Disposal」› 筛选「不可售库存 > 0」› 点「全部」› 保存
- 提交后状态显示「待提交」，**需找对应事业部经理提醒 AK 提交订单**，之后状态变为「已提交」
- 费用参考：标准尺寸 **\$0.15–\$0.30/件**；大件 **\$0.50–\$1.00/件**
