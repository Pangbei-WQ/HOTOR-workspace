# 复制粘贴大法

> **状态**：draft（待人工终审）

**用途**：把问题原样复制粘贴一遍，中间不加任何解释，非推理模型的准确率能从 21.33% 飙到 97.33%（Google 论文《Prompt Repetition Improves Non-Reasoning LLMs》）。

```text
梵蒂冈的那个圣伯多禄大教堂门口有几根柱子？梵蒂冈的那个圣伯多禄大教堂门口有几根柱子？
```

**使用**：规则——中间不加解释、不说 please、不说 think step by step、不贴示例，原样再来一遍。⚠️ **仅对非推理模型有效**（GPT-4o、Claude 3 Haiku、DeepSeek V3 等）；对推理模型（如 DeepSeek R1）几乎没用，因为它们已经自己学会"先复述题目"了。
