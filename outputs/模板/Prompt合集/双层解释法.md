# 双层解释法

> **状态**：draft（待人工终审）

**用途**：治「好像懂了」。先小白版（生活化语言+例子），再专业版（术语+机制+边界），最后出检查题。

```text
我想学习的是：【填写概念或问题】。
请分两层解释：
第一层，小白版。用生活化的语言和一个具体例子，让完全没有基础的人也能听懂。
第二层，专业版。使用准确术语，讲清核心机制、适用边界和常见误解。
最后请整理出：
1.列出小白说法与专业术语的对应关系；
2.我最容易理解错的地方；
3.3个用于检查我是否真正理解的问题。
```
