# MBTI 人格注入

> **状态**：draft（待人工终审）

**用途**：别写几百字复杂 Prompt 了，开头加一句人格标签，给 AI 一个 MBTI 人格，效果就显著提升。论文依据《心理学增强AI智能体》。

```text
请用 INTJ 的视角来回答我
```

或

```text
请用 ENFP 的风格来生成一段文字
```

**使用**：不需要思维链、精巧指令，一个人格标签即可。进阶可组性格互补的 AI 团队——如 ENFP 创意总监发散 + ISTJ 项目经理过滤 + ENTJ 统筹。差异参考：F 型写故事情感浓度更高，T 型玩囚徒困境背叛率高，I 型比 E 型诚实。
