# Vibe Coding 两大基石

> **状态**：draft（待人工终审）

**用途**：两个口头禅，一个管生成、一个管验证——第一性原理（强制打断类比推理、回到本质）+ 对抗式审查（站在恶意用户角度找茬）。

**① 第一性原理（管生成）**

在你平时说话的末尾加一句：

```text
从第一性原理出发
```

修 bug、设计方案、做架构都适用，任务越复杂越万能。实例：AIHOT 流量路由事故，只修表面小错会堆成屎山，加一句"从第一性原理出发"后揪出 4 月写的底层路由隐患，重构治本。

**② 对抗式审查（管验证）**

开发完的测试流程，让 AI 站在恶意用户/对手角度找茬：

```text
开启多 Agent 帮我进行对抗性审查
```

（Claude Code 场景：开启 Ultracode 对之前开发的功能做对抗式审查。）从一个恶意用户会怎么搞崩系统（如提交 50MB HTML 搞崩 worker）的角度，把整条路径走一遍。节奏：常规开发每次测试都用；每 2–3 周对整个项目做一次从第一性原理出发的全局对抗式审查。
